# Combate-ao-Preconceito-
é um site educativo desenvolvido em HTML5 e CSS3 que busca conscientizar sobre os diferentes tipos de preconceito, seus impactos na sociedade e formas de promover respeito, empatia e inclusão. O projeto apresenta um design moderno, responsivo e informativo, incentivando a valorização da diversidade e dos direitos humanos.
